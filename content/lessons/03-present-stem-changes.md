# Present stem changes

In some verbs the vowel in the stem changes when it is stressed. It changes in every person except nosotros and vosotros, because there the stress falls on the ending.

## Forms

There are three patterns:

- **e → ie**: pensar (pienso), querer (quiero), empezar (empiezo)
- **o → ue**: poder (puedo), volver (vuelvo), encontrar (encuentro), dormir (duermo)
- **e → i**, only in -ir verbs: pedir (pido), seguir (sigo)

Jugar is the only verb that changes **u → ue** (juego).

The endings stay regular. Only the stem changes.

## Examples

- *Quiero un café.* I want a coffee.
- *¿Puedes ayudarme?* Can you help me?
- *Vuelvo a las ocho.* I'm back at eight.
- *Pido la cuenta.* I'll ask for the bill.
- *Jugamos al fútbol los sábados.* We play football on Saturdays.
